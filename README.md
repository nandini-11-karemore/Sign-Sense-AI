# 🎨 SketchAI - AI Virtual Painter

SketchAI is an AI-powered virtual painting application that allows users to draw in the air using hand gestures. It uses computer vision to track the user's hand in real time and converts finger movements into digital drawings.

---

## ✨ Features

- ✋ Real-time hand tracking
- 🎨 Air drawing using index finger
- 🌈 Multiple color selection
- 🧹 Clear canvas
- ↩️ Undo last stroke
- 📷 Live webcam interface
- ⚡ Smooth drawing experience

---

## 🛠️ Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy


---

## 🎮 Controls

| Gesture | Action |
|----------|--------|
| Index Finger | Draw |
| Index + Middle Finger | Select Toolbar |
| Undo | Removes last stroke |
| Clear | Clears canvas |
